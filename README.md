# The Writer's Room

**The Writer's Room** is a psychological horror puzzle experience that explores the boundaries between creativity and madness.

## 💡 The Inspiration
This project was born from a unique spark—an idea shared by a user on social media. They envisioned a game where the environment isn't just a setting, but a manifestation of a writer's fractured psyche. This game is our first step toward bringing that vision to life.

## 👁️ Visual Implementation
To capture the unsettling nature of the original idea, we've implemented several key visual elements:
- **Grainy Film Overlay:** A subtle noise effect that creates a sense of age and instability, as if you're watching a fading memory.
- **Dynamic Vignetting:** The edges of the screen darken and shift, mirroring the claustrophobia of being trapped in one's own thoughts.
- **Atmospheric Lighting:** Deep shadows and high-contrast lighting emphasize the isolation of the study.
- **Psychological Cues:** Every object in the room—the ticking clock, the silent typewriter, the dusty bookshelf—is designed to feel like a piece of a larger, darker puzzle.

## 🛠️ Current Status: First-Stage Prototype
This is currently a **first-stage prototype**. We are focusing on establishing the core atmosphere, visual identity, and basic interaction mechanics. 

### What's included:
- Immersive point-and-click exploration.
- Atmospheric soundscape (wind, ticking clocks, and whispers).
- Initial puzzle elements and environmental storytelling.
